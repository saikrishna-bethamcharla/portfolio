# Sai Krishna Bethamcharla — Portfolio

An interactive, high-fidelity portfolio featuring:
- **Apple Dark Aesthetic Hero**: Minimal obsidian `#000000` canvas with red ambient radial glow.
- **3D VHS Filmography Shelf**: Interactive physically-modeled 3D cuboid shelf inspired by Leon Vasari's archival aesthetics, showcasing categorized client and cinematic projects with ink-diffusion inspection sheets.

## Categories & Works
- **Websites**: Vasudha Pharma Systems, Zai Labs AI Platform, Pranic Healing Portal
- **Cinematic Videos**: The Door at 11:47, Odyssey Narrative, Noon in Ashes
- **Motion & Post-Production**: GMCKS Documentary, Neo Belva Commercial, Green Field International
- **Brand Systems**: Aura Organics Luxury, Virupaksha Sanctuary, The Red Door Agency
